# Code of Conduct

SML aims to be a welcoming, technical community.

We expect contributors and maintainers to:
- Be respectful, constructive, and patient with people of different skill levels and backgrounds.
- Critique code and ideas rather than making personal attacks.
- Avoid harassment, intimidation, discrimination, or publishing others' private information.
- Provide reproducible examples and be receptive to review.

Unacceptable behavior includes harassment, discriminatory remarks, threats, deliberately disruptive participation, or unwanted publication of private information.

Project maintainers may edit or remove inappropriate comments, reject contributions, and restrict participation when necessary. Report conduct problems privately to the maintainer via the repository owner's contact information, rather than publishing private details in an issue.

This policy applies to issues, pull requests, discussions, and other official project spaces.
