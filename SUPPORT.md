# Support

For usage questions, start with the [README](README.md), [language guide](docs/language.md), [Go API](docs/go-api.md), and [CLI reference](docs/cli.md). Run the examples and search [existing issues](https://github.com/AmpedWasTaken/SML/issues) before opening a new one.

For reproducible bugs, use the bug-report template. For additions that change SML syntax or the public Go API, start with a feature request and explain the portability of the use case.

SML is a library for rendering terminal UI views. Full-screen event loops, mouse listeners, command execution, remote connections, identity, and authorization must be implemented by the embedding Go application.

For security-sensitive findings, follow [SECURITY.md](SECURITY.md) instead of filing a public issue.
